# ปฏิทินงานประจำเดือน (เว็บแยกต่างหาก — ไม่เกี่ยวกับระบบ RMA เดิม)

เว็บนี้แยกอิสระ 100% จากเว็บ "RMA ตารางงานทีม" — คนละไฟล์ คนละ Google Sheet คนละ Apps Script
ใช้สำหรับใส่ "งานประจำเดือน" ที่มี **ชื่องาน + แบรนด์** เป็นหลัก ทีมทุกคนเห็นข้อมูลเดียวกัน (แชร์กัน)

## สิ่งที่ทำได้
- ปฏิทินรายเดือน ใส่งานลงวันที่ได้ ระบุแบรนด์ (Chery / MITSU / Ford / OJ) แยกสีชัดเจน
- เพิ่ม/ลบแบรนด์เองได้จากหน้าเว็บ (ปุ่ม 🏷️ จัดการแบรนด์)
- กรองดูเฉพาะแบรนด์ได้ (ปุ่มชิปด้านบน)
- รายการงานทั้งเดือนแบบลิสต์ด้านล่างปฏิทิน

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. สร้าง Google Sheet ใหม่
สร้างไฟล์ Google Sheet ใหม่ (ชื่ออะไรก็ได้ เช่น "ฐานข้อมูลปฏิทินงานประจำเดือน") — **ต้องเป็นไฟล์ใหม่ ไม่ใช่ไฟล์ของระบบ RMA เดิม**

### 2. ใส่โค้ด Apps Script
เปิดไฟล์ Sheet ที่สร้าง → ส่วนขยาย (Extensions) → Apps Script
- ไฟล์ `รหัส.gs` (Code.gs) → ลบทั้งหมด → วางโค้ดจากไฟล์ `apps-script/Code.gs`
- กด **+ ไฟล์ → สคริปต์** ตั้งชื่อ `Config` → วางโค้ดจากไฟล์ `apps-script/Config.gs`
- ในไฟล์ Config: แก้ `SHEET_ID` เป็น ID ของ Sheet ที่สร้าง (ดูได้จาก URL ระหว่าง `/d/` กับ `/edit`)
- Ctrl+S

### 3. รัน setupSheets
เลือกฟังก์ชัน `setupSheets` จากเมนูด้านบน → กด ▷ เรียกใช้ → อนุญาตสิทธิ์ตามที่ขอ
(จะสร้างชีต Tasks และ Brands พร้อมใส่แบรนด์เริ่มต้น Chery/MITSU/Ford/OJ ให้อัตโนมัติ)

### 4. Deploy เป็น Web App
การทำให้ใช้งานได้ (Deploy) → ทำให้ใช้งานได้ใหม่ (New deployment) → เลือกประเภท **Web app**
- Execute as: **Me**
- Who has access: **Anyone**
→ กด Deploy → คัดลอก URL ที่ได้ (ลงท้ายด้วย `/exec`)

### 5. ใส่ URL ในเว็บ
เปิดไฟล์ `config.js` → แก้ `API_URL` เป็น URL ที่คัดลอกมา → บันทึก

### 6. อัปโหลดขึ้น GitHub Pages
อัปโหลดทั้งโฟลเดอร์ `monthly-calendar` (index.html, style.css, config.js, api.js, script.js)
ขึ้น GitHub เป็น repo ใหม่ หรือโฟลเดอร์ย่อยในเว็บโฮสติ้งที่ใช้อยู่ก็ได้ (ไม่บังคับต้องอยู่ repo เดียวกับ RMA)
เปิดใช้ GitHub Pages แล้วเข้าลิงก์ที่ได้ เป็นอันเสร็จ

## หมายเหตุ
- ลบงาน/ลบแบรนด์ในเว็บนี้เป็นการลบถาวร (ไม่มีถังขยะ) เพื่อความเรียบง่าย — ถ้าลบแบรนด์ที่มีงานผูกอยู่ งานจะยังอยู่แต่จะไม่มีชื่อแบรนด์กำกับ
- ไม่มีระบบแจ้งเตือน ไม่มี Login ไม่เชื่อมกับปฏิทินทีม/ระบบ RMA เดิมใดๆ ทั้งสิ้น
